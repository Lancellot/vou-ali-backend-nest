## Sobre o projeto

O **Vou Ali** é uma aplicação para planejamento e controle de viagens. A proposta é permitir que o usuário organize viagens, atividades, despesas e acompanhe um dashboard com o status geral do planejamento.

## Funcionalidades previstas

- Autenticação com login e logout.
- Cadastro de usuário.
- Gerenciamento de viagens com CRUD completo.
- Organização de itinerário com atividades por viagem.
- Controle de despesas previstas e realizadas.
- Visualização de dashboard com indicadores da viagem e do orçamento.

## Tecnologias previstas

### Frontend

- React.js
- Tailwind CSS

### Backend

- Node.js
- NestJS
- JWT
- Bcrypt

### Banco de dados

- PostgreSQL
- Prisma ORM

### Versionamento e deploy

- Git e GitHub
- Vercel para frontend
- Render para backend e banco de dados

## Estrutura do cronograma

O cronograma do trabalho foi organizado em 8 semanas, contemplando:

- levantamento de requisitos e análise
- projeto e modelagem de dados
- configuração de ambiente e banco de dados
- desenvolvimento do backend
- desenvolvimento do frontend
- integração das funcionalidades principais
- testes, depuração e refatoração
- implantação e documentação final

## Como executar o backend

```bash
npm install
npm run start:dev
```
